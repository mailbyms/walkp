# WalkP · 步频计

一个用于测量**走路步频**（steps per minute, spm）的 Android 应用。只需加速度计，无需任何传感器权限，支持手持与口袋两种携带方式，支持锁屏后台长时间记录。

## 功能

- **实时步频**：大字号显示当前步频，亮屏低头可见
- **1 分钟平均**：最近 60 秒有效读数的滑动平均
- **60 秒趋势曲线**：实时滚动曲线，直观看节奏稳定性
- **手持 / 口袋自适应**：一键切换携带方式，算法参数自动调整
- **后台长时记录**：前台服务保活，锁屏、切后台持续采集，通知栏低打扰显示读数
- **历史会话**：每次记录自动保存，含时长、平均步频、估算步数、每分钟趋势图

## 技术要点

- **算法**：加速度计三轴模值 → 时间戳重采样到 50 Hz → 去趋势 → 4 秒滑动窗 FFT → 1–3 Hz 内抛物线插值取主峰，叠加时域峰值检测融合输出
- **门控**：RMS 能量 + 主峰突出度 + 峰间隔规律性（变异系数）三重判据，有效排除静止、摇晃与乘车振动
- **精度**：合成信号（含噪声与 ±15% 采样抖动）下 80–160 spm 范围最大误差 **0.74 spm**，12 个单元测试覆盖
- **架构**：Kotlin + Jetpack Compose；DSP 核心为零依赖纯 Kotlin，可离线单测与回放调参；前台服务持有采集引擎，UI 只是观察器；Room 持久化会话

## 构建

```bash
# Windows (Git Bash) / macOS / Linux
./gradlew :app:assembleDebug        # 构建 APK
./gradlew :app:testDebugUnitTest    # 运行单元测试（含精度报告）
```

要求：JDK 17+，Android SDK 35。

## 使用建议

- **手持**：自然摆臂行走，不要低头盯着屏幕看（手臂僵住会丢信号，读数会显示「未检测到」）
- **口袋**：手机屏幕朝内朝外均可，算法与姿态无关
- **校准**：用手机节拍器 App 设 100/120/140 BPM 跟着节奏走，对比读数验证精度
